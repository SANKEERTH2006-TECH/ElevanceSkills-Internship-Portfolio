# 📌 About This Repository

This repository serves as the **master portfolio** for my **ElevanceSkills Data Science Internship**.

Throughout the internship, I successfully completed **six industry-oriented Artificial Intelligence and Machine Learning projects** by extending the original GenAI training project into real-world chatbot applications.

Each project demonstrates different AI capabilities, including Retrieval-Augmented Generation (RAG), multimodal reasoning, medical question answering, semantic research paper search, sentiment-aware conversations, and multilingual conversational AI.

Every project has been independently developed, documented, tested, and published on GitHub with complete source code and documentation.
